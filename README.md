## 🚀 使用方法

### 本地开发
1. 在浏览器中打开 `index.html`
2. 或使用本地服务器：
   ```bash
   # 使用Python
   python -m http.server 8000
   
   # 或使用Node.js
   npx http-server
   ```
3. 访问 `http://localhost:8000`

### 部署
1. 将所有文件上传到您的web服务器
2. 确保目录结构保持一致
3. 配置服务器支持HTML、CSS和JavaScript
